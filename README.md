# 밥장부 직원용 (PoC)

직원이 스마트폰으로 음식점 선금(충전)과 사용액을 기록하고, 음식점별 잔액·사용현황을 한눈에 보는 초간편 웹앱 PoC입니다.

**👉 바로 사용하기: https://nulmaru.github.io/bapjangbu-staff/**

## 특징
- 회원가입·로그인 없음 — 최초 1회 이용 지역(시·군·구)만 설정
- 데이터는 내 스마트폰 브라우저(localStorage)에만 저장, 서버 전송 없음
- 사용액 입력 3터치 이내 (음식점 카드 터치 → 금액 버튼 → 저장)
- **자연어 입력**: "강경불고기에 오늘 12000원 사용했어" 한 줄로 기록 (규칙 기반 파싱, 기기 내 처리)
- 충전은 9,000원 배수 원터치 버튼 (9,000 / 18,000 / 27,000원 …)
- 백업(JSON 내보내기)·복원으로 기기 변경 대비

## 사용 방법
1. 위 URL 접속 → 이용 지역 선택 (예: 광진구)
2. 홈에서 [음식점 등록] → 음식점명·동명으로 검색해 선택 (없으면 자유 입력)
3. 충전·사용을 버튼으로 기록하거나, 홈의 입력창에 문장으로 입력
4. 스마트폰 브라우저의 "홈 화면에 추가"로 앱처럼 사용

## 기술 구성
- 단일 `index.html` (HTML+CSS+JS 인라인, 프레임워크·빌드 도구 없음)
- 음식점 검색은 현재 광진구 샘플 20곳 내장 — 공공데이터(일반음식점 인허가 목록) 연결은 다음 단계
- 상세 요구사항: [밥장부-직원용_PoC계획서.md](밥장부-직원용_PoC계획서.md)
